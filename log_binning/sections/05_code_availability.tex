\section*{Code Availability}

All numerical experiments, synthetic-data generation routines, figure-generation functions, and the complete source of these lecture notes are publicly available at \url{https://github.com/ozsp12/notes_econophys} in the \texttt{log\_binning} directory. The repository contains the Python routines used to reproduce the histogram, CCDF, bin-mean, and Newman-style power-law figures, together with the numerical output table, the LaTeX source, and the BibTeX database. Random-number generation uses fixed seeds so that the computational results reported here can be reproduced from the documented dependencies.
